# 🏙️ Visit Antwerp by Walk

> A self-guided walking tour of Antwerp's most iconic spots — right in your browser.

🌍 **[Open the interactive map →](https://antwerp.robermamani.com)**

---

## What is this?

An interactive web map that builds a real walking route through Antwerp's highlights, complete with turn-by-turn street geometry, estimated distance, and walking time.

## Features

- 🗺️ Real walking route via Mapbox Directions API
- 📍 Numbered stops with info popups
- 🚶 Distance & time estimates
- 📱 Works on mobile and desktop
